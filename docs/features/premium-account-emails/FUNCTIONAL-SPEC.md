# Spécification fonctionnelle — E-mails transactionnels premium

## Utilisateurs concernés

Personnel clinique, administrateurs et patients recevant un mot de passe temporaire ou un code de sécurité.

## Expérience attendue

L'e-mail doit inspirer confiance immédiatement : marque identifiable, objet explicite, salutation personnalisée, information principale mise en évidence, délai d'expiration et consigne de confidentialité. Il doit rester compréhensible lorsque les images ou le HTML sont désactivés.

## Contenus couverts

- Création de compte et mot de passe temporaire.
- Code de connexion du personnel.
- Réinitialisation de mot de passe.
- Code d'accès patient.

## Critères

- Aucun secret dans l'objet ou le pré-en-tête.
- Code lisible et copiable.
- Pas de lien ni de bouton trompeur.
- Mention claire de l'absence d'action à effectuer si la demande n'émane pas du destinataire.
