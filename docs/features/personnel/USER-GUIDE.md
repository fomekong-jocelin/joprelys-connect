# Guide Utilisateur — Gestion du Personnel Clinique (STORY-0104)

## 1. Accès

L'écran de gestion du personnel est accessible à l'administrateur de clinique depuis :

```text
/clinic/staff
```

Un raccourci est aussi disponible depuis le tableau de bord clinique pour le rôle `ADMIN_CLINIQUE`.

## 2. Lister l'équipe

La page affiche les collaborateurs rattachés à la clinique :

- nom complet ;
- adresse e-mail ;
- rôle clinique ;
- statut actif ou suspendu ;
- date de création.

## 3. Inviter un collaborateur

1. Cliquer sur **Inviter un collaborateur**.
2. Renseigner le nom complet, l'e-mail et le rôle.
3. Valider le formulaire.
4. Copier le mot de passe temporaire affiché dans le bandeau de succès.

Le mot de passe temporaire est affiché uniquement après la création du compte. Il doit être transmis au collaborateur par un canal sécurisé.

## 4. Modifier un collaborateur

1. Cliquer sur **Modifier** sur la ligne du collaborateur.
2. Mettre à jour le nom ou le rôle.
3. Enregistrer.

L'adresse e-mail n'est pas modifiable depuis cet écran.

## 5. Suspendre ou réactiver un compte

Le bouton d'action de statut permet :

- de désactiver un compte actif ;
- de réactiver un compte suspendu.

Un collaborateur désactivé ne peut plus se connecter.
