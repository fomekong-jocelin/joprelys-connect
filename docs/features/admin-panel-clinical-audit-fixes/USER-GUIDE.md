# Utilisation des corrections

Dans Organisation hospitalière, choisir la discipline d'un service puis saisir son intitulé local si nécessaire (ex. Chirurgie septique). Le code catalogue assure toujours l'identité de discipline. Dans Collaborateurs, ouvrir les affectations d'un médecin ou infirmier et sélectionner Praticien responsable / chef de service ou Cadre de santé / infirmier major avec sa période de validité.
Dans la configuration spatiale, urgences et néonatologie peuvent recevoir un profil hospitalier. Configurer séparément les places/lits et affectations ; les nouveaux types ambulatoires n'ajoutent aucune capacité automatiquement.
Le journal accessible depuis le dashboard est le journal des autorisations RBAC. Configuration interopérabilité affiche l'état de l'accès API et mène à la fiche de l'établissement pour ses clés.
Un profil sans affectation reste modifiable. Une panne des affectations affiche un avertissement sans bloquer les données personnelles.
Dans Mon profil, le médecin peut importer sa signature au format PNG ou JPEG (2 Mo maximum), puis enregistrer les modifications du profil. Le serveur crée un vrai fichier PNG ; un PNG transparent est recommandé, sa transparence est conservée. L'image est réduite proportionnellement à 500 pixels sur son côté le plus long si nécessaire. Un administrateur autorisé peut également préparer cet asset depuis la fiche du médecin. La signature enregistrée apparaît dans les PDF de consultation et de prescription selon le circuit existant ; une image de signature ne contient pas de certificat cryptographique.
Les médecins rédigent puis signent les prescriptions. La clôture signe et verrouille la consultation ; une ordonnance brouillon associée exige le droit de signature et une prescription complète. Une observation infirmière ne confère pas le droit de prescrire.
Le pharmacien présente numéro/PIN, renseigne sa revue des interactions/doses/contre-indications et la valide, puis trace la délivrance. Les droits de validation et de délivrance sont distincts ; les comptes anonymes ne peuvent plus délivrer. La revue est humaine, aucune analyse automatique n'est revendiquée.
Le scellement est applicatif, avec auteur et heure serveur. La certification ordinale et l'horodatage qualifié exigent une validation et une infrastructure externes.
