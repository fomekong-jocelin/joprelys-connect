# Saisir une consultation

Le contexte patient et ses alertes restent affichés au-dessus du parcours.

1. Choisissez **Saisie manuelle**, **Dictée** ou **Conversation avec le patient**. Ce choix seul n'active pas le microphone.
2. Utilisez le bouton du mode choisi. La saisie manuelle ouvre immédiatement les champs ; les modes vocaux demandent l'accès au microphone.
3. En dictée, arrêtez chaque passage avant de relire la transcription. En conversation, terminez l'enregistrement pour passer à la relecture.
4. Relisez et corrigez la transcription, puis préparez et vérifiez le compte rendu. Acceptez-le explicitement pour remplir le formulaire.
5. Vérifiez les champs, les prescriptions, les examens et les constantes avant de sauvegarder. Les contrôles requis restent actifs.

Si le microphone est indisponible, le bouton **Passer à la saisie manuelle** permet de continuer une fois toute capture arrêtée. Les valeurs déjà présentes dans le formulaire sont conservées lors d'une reprise d'enregistrement ; ce parcours ne sauvegarde pas automatiquement la consultation.
