# FUNCTIONAL-SPEC — Shell de régularisation patient

## Besoin

Un administrateur clinique doit conserver les éléments de navigation de l’application pendant le rapprochement des dossiers URG-TEMP.

## Critères d’acceptation

- L’en-tête, le menu et le fil d’Ariane du shell clinique restent visibles.
- La navigation mobile, les thèmes light/dark et le sélecteur de langue restent accessibles.
- Le contenu métier de la page et ses autorisations ne changent pas.
